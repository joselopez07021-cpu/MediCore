Cómo repetir la revisión (desde backend, con ambos servidores iniciados)
  npm.cmd test
  npm.cmd run test:browser
  npm.cmd run check:system

Desde frontend
  npm.cmd test -- --watch=false
  npm.cmd run build

check:system requiere las cuentas de demostración y sus claves locales actuales.
test:browser requiere Microsoft Edge, Angular en localhost:4200 y permiso para
crear y eliminar una base temporal PostgreSQL. Las capturas se actualizan en
docs/evidencias. Ninguno de estos resultados garantiza ausencia de otros fallos.
